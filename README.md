# AIETHOS — AI Ethics Observatory

Powered by Prof Andy Miah. A static, accessible tracker of AI governance across jurisdictions.

- `source/regulatory/<id>/<id>-entry.json` — one entry per jurisdiction (edit these)
- `node build/extract.js` — regenerates `data/*.json`
- `index.html` — the site (fetches `data/`)

Hosted on GitHub Pages (main, root) at https://aiethos.andymiah.net
